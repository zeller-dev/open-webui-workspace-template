# open-webui

Chat UI, connects to the shared `ollama-net` Docker network. Holds no models
or GPU access of its own — start `../ollama/` first.

## Setup

    cd ../ollama && npm run up      # start Ollama first (creates ollama-net)
    cd ../open-webui
    npm run up                      # auto-creates .env + secret key

## URLs

- Web UI: <http://localhost:${WEBUI_PORT}> (default 3000)

## Commands

    npm run up      # start (runs setup first)
    npm run down    # stop, keep chat history
    npm run reset   # stop and wipe all data
    npm run logs    # tail logs

## First-time in the Web UI

1. Create your account — first account becomes admin, signups auto-disable after.
2. Admin Panel → Settings → Connections — confirm Ollama shows `http://ollama:11434`.
3. Models available in `ollama/` show up in the picker automatically.
4. Admin Panel → Settings → Models — set default model / system prompt.

## Notes

- `WEBUI_SECRET_KEY` is auto-generated by `npm run setup` (called by `up`),
  pinned in `.env` so logins survive rebuilds.
- `TASK_MODEL` handles background title/tag generation — keep it small and
  separate from your main chat model, or every message triggers extra full
  inferences just to name the chat.
- `ENABLE_AUTOCOMPLETE_GENERATION=false` — fires on every keystroke, disabled
  since it's not useful for a solo desktop setup.
- Telemetry is explicitly disabled (`ANONYMIZED_TELEMETRY`, `DO_NOT_TRACK`,
  `SCARF_NO_ANALYTICS`).
- If Ollama isn't running yet (`../ollama` stack down, or `ollama-net`
  doesn't exist), this container will fail to start — start `ollama/` first.
- This service joins two networks: `ollama-net` (internal, to reach Ollama by
  name) and `webui-lan` (normal bridge, defined in this file) so the
  published port can actually bind on Docker Desktop — see the `networks:`
  comment in `docker-compose.yml`. This means open-webui itself does have a
  route to the internet (Ollama does not) — see the note about the RAG
  embedding model below if that matters to you.
- **RAG embeddings run through Ollama, not Hugging Face.** By default, Open
  WebUI fetches `sentence-transformers/all-MiniLM-L6-v2` from huggingface.co
  on first boot for its RAG embedding model — a real outbound call this repo
  never asked for. `RAG_EMBEDDING_ENGINE=ollama` +
  `RAG_EMBEDDING_MODEL=embeddinggemma-300m-q8-0` route it through the local
  Ollama instance instead. That model (`unsloth/embeddinggemma-300m-GGUF`,
  Q8_0) was fetched via the trusted-quantizer scripts and imported the same
  way as any chat model — see `ollama/README.md`. If you swap in a different
  embedding model, re-import it into Ollama first and update both env vars
  in `open-webui/.env` and `open-webui/docker-compose.yml`.
