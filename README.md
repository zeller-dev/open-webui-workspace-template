# local-llm-stack

Ollama + Open WebUI, containerized. Everything lives here — no host installs beyond
Docker and the Nvidia driver/toolkit.

## Prereqs (host only)
- Nvidia driver
- nvidia-container-toolkit
- Docker + Compose v2
- Node/npm (just to run the scripts)

## Setup

    npm run up

First run auto-creates `.env` from `.env.example` and generates a random
`WEBUI_SECRET_KEY` for you (via `npm run setup`, which `up` calls automatically).
Re-running never overwrites an existing key.

## Commands

    npm run setup         # (re)generate .env / secret key without starting anything
    npm run up            # start (runs setup first)
    npm run down          # stop, keep model data
    npm run reset         # stop and wipe all data (volumes)
    npm run logs          # tail logs
    npm run pull -- qwen3:14b     # pull a chat model (note the --)
    npm run pull-embed            # pull nomic-embed-text (better RAG embeddings)
    npm run list                  # list installed models

## URLs
- Ollama API: http://localhost:${OLLAMA_PORT} (default 11434)
- Web UI: http://localhost:${WEBUI_PORT} (default 3000)

## First-time in the Web UI
1. Create your account at the URL above — first account becomes admin, signups
   auto-disable after that.
2. Admin Panel → Settings → Connections — confirm Ollama shows `http://ollama:11434`.
3. Pull a couple of models at different sizes (fast one + main daily driver) via
   `npm run pull`. They show up in the model picker automatically.
4. Admin Panel → Settings → Models — set your default model and, optionally, a
   default system prompt per model.
5. Settings → Documents — embedding model defaults to `all-MiniLM-L6-v2` (fast).
   Switch to `nomic-embed-text` for stronger RAG quality (`npm run pull-embed`
   first). Re-upload any docs after switching — old embeddings don't carry over.

## Structure
- `docker-compose.yml` — the two services + healthcheck, log rotation, GPU passthrough
- `package.json` — npm script shortcuts around docker compose
- `scripts/setup.js` — bootstraps `.env` and generates `WEBUI_SECRET_KEY`
- `.env` — your local config (ports, secret key, CORS, default model, auth). Gitignored.
- `.env.example` — template to copy from, safe to commit
- `.gitignore` — keeps `.env`, `node_modules`, and logs out of version control

Model weights and chat history live in Docker named volumes (`ollama_data`,
`open_webui_data`), not in this folder — `npm run reset` deletes them.

## Notes
- Healthcheck on `ollama` means `open-webui` waits until Ollama is actually ready.
- Log rotation (10MB x 3 files per service) keeps container logs from growing unbounded.
- `WEBUI_SECRET_KEY` is pinned in `.env` (auto-generated by `npm run setup`) so logins
  survive container rebuilds — without it Open WebUI generates a new one on every boot,
  which invalidates sessions on rebuild.
- `WEBUI_AUTH=false` disables the login screen entirely if this stays on a trusted
  machine only.
- `CORS_ALLOW_ORIGIN=*` is fine for localhost-only use. Set it to your actual origin
  (e.g. `http://192.168.1.50:3000`) if you expose this beyond your machine.
- First boot downloads the embedding model (~2-3 min) — the "backend required" error
  on first load usually just means it's still starting up. Reload once it's done.
